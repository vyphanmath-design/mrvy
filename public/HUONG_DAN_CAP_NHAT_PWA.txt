1. Trong GitHub dự án mrvy, mở thư mục public.
2. Thay file public/app.html bằng file app.html trong bộ này.
3. Tải thêm các file sau vào chính thư mục public:
   - manifest.webmanifest
   - service-worker.js
   - thư mục icons
4. Commit changes để Vercel tự deploy.

Lưu ý:
- Không thay pages/api/rpc.js
- Không sửa next.config.js
- Không chạy SQL
- Nếu thầy đã từng đặt ảnh đại diện riêng trong hệ thống, ảnh đó vẫn được ưu tiên hiển thị. Logo mới đẹp hơn sẽ dùng làm logo mặc định khi chưa có ảnh đại diện riêng.

Cách kiểm tra:
- Truy cập https://mrvy.vercel.app/manifest.webmanifest xem có mở được không.
- Trên điện thoại Android: mở Chrome > vào mrvy.vercel.app > menu 3 chấm > Cài đặt ứng dụng / Thêm vào màn hình chính.
